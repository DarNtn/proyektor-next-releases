Transparencia de datos

Política de privacidad

Última actualización: 19 de septiembre de 2026

Versenda es una aplicación gratuita de escritorio mantenida por DarNtn. Puedes usarla como Invitado sin vincular ninguna cuenta. Esta política explica qué datos permanecen en tu equipo, cuáles se envían al vincular una cuenta y cómo controlarlos.

1. Responsable y contacto

El proyecto Versenda, mantenido por DarNtn, es responsable de las funciones de la aplicación descritas aquí. Para consultas de privacidad, soporte o solicitudes relacionadas con tus datos, escribe a support@versenda.uk. Para problemas generales también puedes usar las incidencias públicas del proyecto; no publiques allí datos personales ni archivos privados.

2. Uso como Invitado y almacenamiento local

La aplicación no exige iniciar sesión. Biblias descargadas, fondos importados, cancioneros, notas, anuncios, favoritos, listas de reproducción y preferencias se guardan en este equipo. Como Invitado, Versenda no sube esos datos a Google Drive. Algunas funciones, como descargar recursos, reproducir contenido de YouTube, abrir páginas externas o comprobar actualizaciones, sí necesitan Internet y contactan a los servicios correspondientes.

3. Qué ocurre al vincular Google

Si decides vincular una cuenta, el inicio de sesión se realiza en el navegador del sistema mediante Google. Versenda recibe un identificador de cuenta, nombre, correo electrónico y, si está disponible, foto de perfil para mostrar tu cuenta y asociar tus respaldos. También obtiene tokens de autorización para acceder al espacio de respaldo. El token de renovación se guarda en el almacén de credenciales del sistema operativo; el token de acceso se mantiene durante la sesión. No solicitamos tu contraseña.

Proveedor Permisos solicitados Uso
Google openid, email, profile, drive.appdata Identificar la cuenta, mostrar nombre/foto y guardar o recuperar respaldos en la carpeta privada de datos de Versenda dentro de Google Drive. El permiso no da acceso a tus documentos generales de Drive.

Los datos de la cuenta se usan para autenticación, visualización del perfil y sincronización. No se venden, no se usan para publicidad ni se comparten con otros usuarios. El respaldo se envía directamente desde la aplicación a Google Drive; Versenda no opera un servidor propio que aloje copias de esos archivos. Google procesa los datos según sus propias políticas y la configuración de tu cuenta.

4. Qué se respalda y cómo se sincroniza

Cuando la cuenta está vinculada, la aplicación puede respaldar automáticamente, mientras permanece abierta y tiene conexión: configuraciones; Biblias y fondos añadidos fuera del instalador; cancioneros; notas y anuncios; la lista de YouTube del Reproductor; configuración de Adicionales; versículos, fondos y canciones favoritos; y el fondo seleccionado en el Visor. Estos datos pueden incluir texto o imágenes que tú hayas incorporado. Las Biblias y fondos incluidos con el instalador no se vuelven a subir.

En otra computadora, Versenda compara el respaldo con los datos locales. Si encuentra diferencias, te permite elegir por categorías qué importar y advierte cuándo un elemento coincidente se reemplazará. Los datos diferentes se combinan cuando corresponde. La aplicación conserva una copia local de recuperación antes de importar. Si trabajas sin conexión, los cambios permanecen en tu equipo hasta que vuelvas a conectarte con la aplicación abierta.

No se sincronizan contraseñas, tokens, claves API, identificadores de analítica, historial de sesión ni detalles de pantallas y monitores. Los respaldos no cuentan con cifrado de extremo a extremo propio de Versenda; su protección depende también de la seguridad de tu equipo y de Google Drive.

5. Mensajes de soporte

Si usas el formulario de soporte de una compilación que lo tenga configurado, se envían el tipo y contenido del mensaje, los datos de contacto que escribas y datos técnicos de la aplicación y del idioma para responderte. No incluyas información sensible si no es necesaria para el problema.

6. Conservación, eliminación y control

Los datos locales permanecen hasta que los elimines en la aplicación o en tu equipo. Los respaldos permanecen en tu cuenta de Google Drive hasta que elimines los datos de la aplicación en ese servicio o solicites ayuda por el correo de soporte. Cerrar sesión o revocar el permiso detiene el acceso futuro de Versenda, pero no borra automáticamente los respaldos ya guardados ni los datos locales. Desde Google puedes revocar el acceso concedido a Versenda en la configuración de tu cuenta.

Para consultar o solicitar ayuda con tus datos, escribe a support@versenda.uk. Los plazos de conservación de los datos alojados por Google y GitHub dependen de sus servicios y de las opciones configuradas para cada cuenta o proyecto.

7. Esta página y servicios externos

Este sitio está alojado en GitHub Pages. No incluye formularios de datos personales, scripts de seguimiento ni cookies propias. El enlace de descarga abre el último release en GitHub. GitHub puede procesar información técnica necesaria para entregar la página y la descarga conforme a su declaración de privacidad. Los enlaces a GitHub Releases, YouTube y Google abren servicios externos con sus propias políticas.

8. Cambios en esta política

Si cambia la forma en que Versenda accede, utiliza o comparte datos, actualizaremos esta página y su fecha antes de distribuir la función correspondiente. Puedes volver a esta página desde el sitio o desde el enlace de privacidad en la aplicación.
